# 吾爱森鹿语 WordPress 主题

这是一个独立的 WordPress 主题，按 `sluyu.com` 的首页结构和视觉比例重写：白色导航、视频感 Hero、粉色强调、四组快捷入口、签到/排行侧栏、五列图片卡片和文章详情下载区。主题同时加入了从 Zb_Acg 视觉中重写的彩色功能卡、玻璃拟态、标题徽章、返回顶部、移动底部导航、图片灯箱、页面加载动画、彩色滚动条和可选粒子背景。

主题目录：`wuai-sluyu/`

## 安装要求

- WordPress 6.0+
- PHP 7.4+
- 服务器启用固定链接重写（宝塔 Nginx/Apache 均可）

主题可独立启用。主题设置实际接入用户提供的 Zibll 源码中的 Codestar Framework 2.2.0 核心、子比管理面板类、上传控件及样式；文章、评论和媒体使用 WordPress 功能。社区业务由本主题独立实现，商城、结算和订单对接 WooCommerce，并非移植子比的支付或授权代码。框架来源与适配范围见 `wuai-sluyu/THIRD-PARTY.md`。

## 安装

1. 将 `wuai-sluyu` 上传到 `wp-content/themes/`。
2. 在 WordPress 后台启用“吾爱森鹿语”。
3. 进入“吾爱森鹿语 → 主题设置”配置 Hero、广告、首页栏目和 GitHub 仓库。
4. 创建分类：`资讯`、`游戏资源`、`图包`、`美图`，并给文章设置特色图片。
5. 在文章编辑页填写“游戏资源信息”，可显示版本、平台、网盘地址、提取码和标题徽章。
6. 进入“吾爱森鹿语 → 主题设置 → 页面&显示 → 显示&布局”，按服务器性能开关粒子背景、灯箱、加载动画、玻璃卡片和移动端导航。

后台设置使用真实 CSF 与子比设置层，采用“全局&功能、页面&显示、文章&列表、功能&权限、用户&互动、支付&付费、商城&商品、社区&论坛、扩展&增强”九大根组及子栏目。在线更新、备份&导入位于“扩展&增强”，支持多级导航、字段搜索、AJAX 保存、媒体选择、颜色选择器、分组重置与全部重置。旧版配置继续使用原 option，无需重新填写。

v1.6 后台整理包含 29 个子栏目：小工具与菜单、独立服务页面、站点公告、文章分类与下载权限、注册与邀请码、用户安全、消息通知、积分签到、支付、商品订单、社区圈子和供求审核均有对应入口。签到配置归入“用户&互动”，支付不再与非现金签到积分混在一起。邀请码、圈子授权、公告和悬赏仍通过原有的独立 nonce / 审核流程保存，主题设置不会复制一套绕过校验的开关。未启用 WooCommerce 时显示依赖提示，不输出无效商品、订单或支付设置链接；订单入口按 HPOS 状态选择。

旧版在线更新、备份恢复、基础设置等书签会自动定位到新栏目。后台菜单支持手机端、键盘 Enter / Space 打开与 Escape 关闭；配置保存、恢复与导入仍沿用原数据键。

配置发生更改前自动保留历史备份，最多 20 份；可手动备份、恢复、导出 JSON 和导入。备份仅包含主题设置，文章与媒体请单独备份。所有写入路径共用字段校验，配置接口校验管理员权限及 WordPress nonce。

首页只显示 WordPress 中已发布的文章，按照“首页栏目”配置读取分类；没有匹配的配置分类时，使用站点已有分类。空栏目显示“暂无已发布文章”，不会自动生成或展示演示文章。首页侧栏的“最新文章”同样读取已发布文章。

主题默认将文章链接输出为 `数字.html`，用于兼容原站的数字文章地址；启用主题后请到“设置 → 固定链接”点击一次保存，刷新重写规则。

## GitHub 更新

发布新的 GitHub Release 时，上传顶层目录为 `wuai-sluyu` 的 ZIP，例如：

```text
wuai-sluyu-v1.4.0.zip
```

后台会通过 GitHub Releases API 检查新版本，不需要在主题中保存 PAT。
“扩展&增强 → 文档&更新”打开时自动检测，点击“检查更新”强制重新查询，无需跳转页面。正式版通道读取最新正式 Release，预发布通道同时检查预发布版本。GitHub 检测结果缓存 1 小时，手动检测绕过缓存。

发现新版本后，当前页显示版本号、Release 更新日志和“在线更新”按钮。点击后先备份主题设置，再由 WordPress 下载、校验并安装主题。彩色进度条显示实际执行阶段（阶段百分比，不是下载字节百分比），刷新页面会恢复进行中的任务。安装权限、重复请求、超时及下载失败均有提示；仅接受所配置仓库的主题 ZIP，不使用整个仓库的自动源码压缩包。ZIP 的目录、必需文件、版本、PHP/WordPress 要求以及 GitHub 提供的 SHA256 都会校验。WordPress 6.3+ 使用内置临时备份恢复失败的安装。

v1.6 使用服务器进程文件锁确认安装是否仍在运行，不再凭“超过两分钟没有进度”取消下载；轮询和旧版的中断接口均为只读，不会覆盖新任务。仅磁盘版本号变化不足以认定完整安装成功。服务器临时目录须可写并支持文件锁；多节点部署仍需统一维护窗口，不将此本地锁视为跨节点分布式锁。

### 启用与配置

1. 更新主题后进入一次 WordPress 后台，使新版重写规则生效。也可以到“设置 → 固定链接”保存。
2. 进入“吾爱森鹿语 → 站内服务管理”。页面无需预创建即可访问；点击“创建缺失的页面与分类”会在 WordPress 中生成可编辑页面，但不会覆盖已有页面、分类或文章。
3. 在“吾爱森鹿语 → 主题设置 → 用户&互动 → 积分与签到”配置签到积分、补签费用；会员商品和优惠码位于“商城&商品 → 会员与优惠”。前台入口已指向实际服务页，原有自定义链接仍优先使用。
4. 在“外观 → 小工具”拖放“森鹿语 · 功能小工具”并选择类型；在后台新增的内容菜单中审核话题、快讯、导航、认证和工单。
5. 启用商城时单独安装 WooCommerce，配置货币、收货 / 邮箱、结算页和支付网关，关闭其“即将推出”模式后才对访客开放。插件本身及支付服务不打包进主题。
6. 会员商品使用 WooCommerce 简单虚拟商品，在商品页填写“吾爱会员有效天数”（正数=天数，-1=长期，0=普通商品），再将商品 ID 填入主题设置。不要仅修改商品描述来授予会员。
7. 文章编辑中的“下载权限”决定下载卡片权限；权限不足时，网盘地址和提取码不会输出到页面。该控制不覆盖管理员自行写在正文中的链接，也不为外部网盘提供防转发能力。

### 业务边界

抓取目录只有前端页面，没有原站服务器接口、支付密钥、数据库或用户数据。本版覆盖主要公开页面和社区交互，但并不声称完整复刻原站 B2 的所有商业规则。v1.2.0 已补齐多选 / PK 投票和头像 / 封面上传；v1.3.0 增加独立隐藏正文、积分下载、供求信息及一次性邀请码；v1.4.0 增加圈主审核 / 精选排序和猜答案；v1.5.0 工作区加入受限的非现金积分经济合同与默认关闭的积分悬赏。完整私密圈子、现金悬赏、担保交易、通用附件、余额充值提现和视频付费阅读尚未发布。现金支付依赖 WooCommerce 支付插件及商户配置，正式上线前必须完成支付渠道沙盒和退款验收；本地测试没有执行外部支付。

积分不是现金，不承诺兑换会员或下载加速。补签和明确确认的正文 / 下载解锁会扣除积分；重复请求同一版本不会重复扣分。部分退款也会撤销该订单的会员授权（保守策略）；其他订单的有效权益保留，若同步故障则临时关闭会员访问等待核验。任务与积分流水在隐私删除时说明保留原因，删除账号时清理；支付记录由 WooCommerce 的隐私政策处理。

v1.5 的积分经济合同是单站点、单一权威数据库的非现金记账集成。多站点会关闭完整余额、流水、签到 / 补签 / 任务、积分解锁、悬赏和经济账号删除；网络级 `wpmu_delete_user()` 也会在 WordPress 开始删除网络数据前被阻断。不要在多站点设置中开启经济合同，也不要把 `events` 表的部分数据当作可用余额。

签到或补签若出现“凭证已保存但计数未完整确认”，请按唯一事件键离线核对并重建 usermeta 投影，不要再次手工加分或扣分。账号删除异常可能保留无 TTL 的全局记账锁；恢复前必须停止所有网页 PHP、CLI、cron / 队列，备份并核对悬赏分配、唯一事件和 users 行，再按精确 token 维护，不能在线猜测解锁或删除流水。部署与恢复边界详见 `FEATURES.md`。

更多逐项范围见 `FEATURES.md`。已有内容不会被自动导入演示文章，也不会复制参考站用户、交易、邀请码和个人联系信息。

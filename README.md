# 吾爱森鹿语 WordPress 主题

这是一个独立的 WordPress 主题，按 `sluyu.com` 的首页结构和视觉比例重写：白色导航、视频感 Hero、粉色强调、四组快捷入口、签到/排行侧栏、五列图片卡片和文章详情下载区。主题同时加入了从 Zb_Acg 视觉中重写的彩色功能卡、玻璃拟态、标题徽章、返回顶部、移动底部导航、图片灯箱、页面加载动画、彩色滚动条和可选粒子背景。

主题目录：`wuai-sluyu/`

## 安装要求

- WordPress 6.0+
- PHP 7.4+
- 服务器启用固定链接重写（宝塔 Nginx/Apache 均可）

主题可独立启用。主题设置实际接入用户提供的 Zibll 源码中的 Codestar Framework 2.2.0 核心、子比管理面板类、上传控件及样式；文章、评论和媒体使用 WordPress 功能。没有移植子比的支付、商城、授权或完整业务功能。框架来源与适配范围见 `wuai-sluyu/THIRD-PARTY.md`。

## 安装

1. 将 `wuai-sluyu` 上传到 `wp-content/themes/`。
2. 在 WordPress 后台启用“吾爱森鹿语”。
3. 进入“吾爱森鹿语 → 主题设置”配置 Hero、广告、首页栏目和 GitHub 仓库。
4. 创建分类：`资讯`、`游戏资源`、`图包`、`美图`，并给文章设置特色图片。
5. 在文章编辑页填写“游戏资源信息”，可显示版本、平台、网盘地址、提取码和标题徽章。
6. 进入“吾爱森鹿语 → 主题设置 → 界面美化”，按服务器性能开关粒子背景、灯箱、加载动画、玻璃卡片和移动端导航。

后台设置使用真实 CSF 与子比设置层，包含概览、基础设置、首页布局、文章与资源、界面美化、SEO、在线更新和备份恢复。支持多级导航、字段搜索、AJAX 保存、媒体选择、颜色选择器、分组重置与全部重置。旧版配置继续使用原 option，无需重新填写。

配置发生更改前自动保留历史备份，最多 20 份；可手动备份、恢复、导出 JSON 和导入。备份仅包含主题设置，文章与媒体请单独备份。所有写入路径共用字段校验，配置接口校验管理员权限及 WordPress nonce。

首页只显示 WordPress 中已发布的文章，按照“首页栏目”配置读取分类；没有匹配的配置分类时，使用站点已有分类。空栏目显示“暂无已发布文章”，不会自动生成或展示演示文章。首页侧栏的“最新文章”同样读取已发布文章。

主题默认将文章链接输出为 `数字.html`，用于兼容原站的数字文章地址；启用主题后请到“设置 → 固定链接”点击一次保存，刷新重写规则。

## GitHub 更新

发布新的 GitHub Release 时，上传顶层目录为 `wuai-sluyu` 的 ZIP，例如：

```text
wuai-sluyu-v1.0.9.zip
```

后台会通过 GitHub Releases API 检查新版本，不需要在主题中保存 PAT。
“在线更新”打开时自动检测，点击“检查更新”强制重新查询，无需跳转页面。正式版通道读取最新正式 Release，预发布通道同时检查预发布版本。GitHub 检测结果缓存 1 小时，手动检测绕过缓存。

发现新版本后，当前页显示版本号、Release 更新日志和“在线更新”按钮。点击后先备份主题设置，再由 WordPress 下载、校验并安装主题。彩色进度条显示实际执行阶段（阶段百分比，不是下载字节百分比），刷新页面会恢复进行中的任务。安装权限、重复请求、超时及下载失败均有提示；仅接受所配置仓库的主题 ZIP，不使用整个仓库的自动源码压缩包。ZIP 的目录、必需文件、版本、PHP/WordPress 要求以及 GitHub 提供的 SHA256 都会校验。WordPress 6.3+ 使用内置临时备份恢复失败的安装。

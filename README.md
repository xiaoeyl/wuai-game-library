# 吾爱森鹿语 WordPress 主题

这是一个独立的 WordPress 主题，按 `sluyu.com` 的首页结构和视觉比例重写：白色导航、视频感 Hero、粉色强调、四组快捷入口、签到/排行侧栏、五列图片卡片和文章详情下载区。

主题目录：`wuai-sluyu/`

## 安装要求

- WordPress 6.0+
- PHP 7.4+
- 服务器启用固定链接重写（宝塔 Nginx/Apache 均可）

主题不复制 Zibll 商业主题核心，也不包含支付、统计、混淆脚本。若服务器已经安装正版 Zibll，主题仍可与其用户、评论和网盘功能并存；没有 Zibll 时也可以独立启用。

## 安装

1. 将 `wuai-sluyu` 上传到 `wp-content/themes/`。
2. 在 WordPress 后台启用“吾爱森鹿语”。
3. 进入“外观 → 吾爱森鹿语”配置 Hero、广告、首页栏目和 GitHub 仓库。
4. 创建分类：`资讯`、`游戏资源`、`图包`、`美图`，并给文章设置特色图片。
5. 在文章编辑页填写“游戏资源信息”，可显示版本、平台、网盘地址和提取码。

主题默认将文章链接输出为 `数字.html`，用于兼容原站的数字文章地址；启用主题后请到“设置 → 固定链接”点击一次保存，刷新重写规则。

## GitHub 更新

发布新的 GitHub Release 时，上传顶层目录为 `wuai-sluyu` 的 ZIP，例如：

```text
wuai-sluyu-v1.0.1.zip
```

后台会通过 GitHub Releases API 检查新版本，不需要在主题中保存 PAT。

## 参考素材

素材来自用户提供的扒站目录，仅保留 Logo、Hero、横幅、广告和四个快捷入口图标；原站中的统计脚本、混淆代码和管理脚本没有复制。
